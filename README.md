# TME 6015 final project: album packaging classifier

Classify any album packaging image (front, back, disc, booklet) into 10 albums. The work lives in
[`project/`](project/README.md), which also holds the data report.

Assignment 2 (the food image classifier) has its own repo, `tme6015-food-classifier`.

## Setup

```
uv sync
```

Creates `.venv` (Python 3.12) from `pyproject.toml` and `uv.lock`. Scripts run from anywhere, for example
`python project/scripts/04_download_project.py`.
